# Albumentations ANPR Training Dataset

This folder is generated by:

```powershell
py -3.13 scripts\augment_yolo_albumentations.py --per-kind 1
```

Input:

```text
data/plate-dataset/datacluster-roboflow-yolo/data.yaml
```

Output:

```text
data/plate-dataset/anpr-augmented-yolo/data.yaml
```

The generator keeps original train/val images, augments training images only, and copies validation images without synthetic weather/noise. The generated augmentation families are:

- fog
- rain
- mud
- blur
- folded/perspective distortion

This is the first dataset selected by `backend/train_resume.py` when it exists.
