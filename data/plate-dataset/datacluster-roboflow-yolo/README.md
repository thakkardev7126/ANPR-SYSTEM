# Merged YOLOv8 ANPR Dataset

This folder is generated by:

```powershell
py -3.13 scripts\merge_yolo_sources.py
```

Default labelled sources:

- `data/plate-dataset/kaggle-yolo`
- `data/plate-dataset/datacluster-yolo`
- `data/plate-dataset/roboflow-yolo`

If a source folder does not contain `data.yaml`, the merge script skips it. That lets the project train immediately with Kaggle + DataCluster while Roboflow credentials are still pending.

Current generated class layout:

```yaml
names:
  0: license_plate
```

To preserve native layout classes from a Roboflow/Indian_LPR source, run:

```powershell
py -3.13 scripts\merge_yolo_sources.py --two-class
```
